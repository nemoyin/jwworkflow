🔄 SSE 实时推流流程

// 前端 EventSource 订阅
const es = new EventSource(`/api/workflows/${wfId}/run/sse`);

// 服务端推送事件
es.addEventListener('node_start', (e) => {  → 节点高亮 + 旋转动画
  highlightNode(e.data.node_id);
});
es.addEventListener('node_output', (e) => {  → 节点下方显示输出预览
  showNodeOutput(e.data.node_id, e.data.output);
});
es.addEventListener('node_done', (e) => {  → 节点变绿色 ✅
  markNodeSuccess(e.data.node_id);
});
es.addEventListener('node_error', (e) => {  → 节点变红色 ❌
  markNodeError(e.data.node_id, e.data.error);
});
es.addEventListener('workflow_done', (e) => {  → 展示最终结果
  showFinalOutput(e.data.output);
});

🤔 确认问题

前端架构设计主要确认：

  • React + React Flow + Ant Design 技术栈是否接受？
  • SSE 推流 实现运行实时可视化 —— 节点逐步高亮、变绿/变红
  • 左侧节点面板拖拽 到画布的方式
  • 或者你更倾向 Vue 等技术栈？
