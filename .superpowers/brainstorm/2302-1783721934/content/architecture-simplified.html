✅ 简化收益

  • 本机一条命令即可启动
  • 仅依赖 PostgreSQL + Python
  • 开发调试零配置
  • MVP 迭代速度快 3-5x

⚠️ 代价

  • 同步执行 → 长任务阻塞线程
  • 无异步队列 → 高并发受限
  • 无对象存储 → 文件管理需后续升级
  • pgvector 性能不如专用向量库

🤔 需要你确认

关键问题：大模型调用是同步还是异步？

工作流中如果包含 LLM 调用（尤其 RAG+长文档），单次可能耗时 10-60 秒。

  • 同步方案：用户发起 → 等待完成 → 看到结果。简单直接，但超时需 SSE 推流
  • 异步方案：用户发起 → 后台执行 → 完成后通知。需加消息队列（保留 Celery+Redis）

你倾向哪种？同步的话这个简化方案直接成立；异步的话需要保留 Celery+Redis。
