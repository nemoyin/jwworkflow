# Phase 9: 补齐 Dify 差距计划

### 批次A（最高优先级）
1. **Prompt IDE** — 独立提示词编辑器，变量插入、多版本、预览
2. **LLMOps** — Token 用量追踪、执行耗时统计、趋势看板
3. **并行执行** — DAG 同层节点并行执行（concurrent.futures）
4. **高级 RAG** — 语义分块 + 重排序（rerank）节点
5. **DSL 导入导出** — 工作流 JSON DSL 导出/导入分享

### 批次B（次优先级）
6. **工具市场** — 工具注册表 + 预置工具（搜索/计算/天气等）
7. **MCP 协议** — MCP Server 端点，外部系统可发现和调用工作流
8. **ReAct Agent** — 升级 Agent 节点为 ReAct 模式（观察→思考→行动→循环）
9. **文件上传增强** — drag-drop 多文件、预览、类型图标
10. **缺失节点** — 补齐 Dify 有但 jwworkflow 无的节点类型
